## Overview

AINumbers provides browser-based fintech workflows for situations where calculations must be repeatable and their outputs easy to inspect. Its deterministic tools create verifiable, hash-chained artifacts, allowing reviewers to follow the origin of a result without installing a separate application.

The complete experience is packaged in one self-contained HTML file. It can be opened and shared across browser environments, while local-only receipt storage keeps generated records on the user's side. Support for OpenChainGraph and MCP adds structured exports and integration options for compliance-focused processes.

## Using AINumbers

AINumbers can serve as a browser workspace for deterministic calculations, artifact review, and compliance-oriented exports:

1. Launch the HTML package in a browser.
2. Choose the required tool or workflow from the browser tool collection.
3. Run the calculation and create its verifiable artifact.
4. Inspect the hash-chained history and any exported records.
5. Select Policy Mandate export when structured sharing is needed.
6. Connect through MCP when the surrounding environment supports integrated automation.

A typical flow looks like this:

- Open the local HTML file
- Provide the requested values
- Create the calculation artifact
- Save or export the receipt locally
- Distribute the export when required by the compliance process
